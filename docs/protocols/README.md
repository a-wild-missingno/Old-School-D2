# Protocol notes

Protocol documents in this directory should be independent, clean-room specifications derived from observations, captures, and static analysis.

Separate observed facts from hypotheses. Use neutral field names until meanings are confirmed.

Suggested sections for each protocol:

- transport
- framing
- byte order
- compression
- serialization
- message identifiers
- request fields
- response fields
- state transitions
- unknown fields
- observed examples
- confidence level
